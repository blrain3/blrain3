## GitHub Space Shooter

我的 GitHub 贡献图变成了太空射击游戏 🚀

每天自动更新，通过 GitHub Actions 生成最新贡献图动画。

**攻击策略**：`random`（随机攻击模式）  
**生成工具**：[gh-space-shooter](https://github.com/czl9707/gh-space-shooter)
